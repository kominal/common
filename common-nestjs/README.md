# Common NestJS

# Environment Variables

## Compiletime Variables

```bash
export NODE_ENV=development
```

## Runtime Variables

```bash
export SYSTEM_API_SECRET=your_system_api_secret
export JWKS_URI=https://your_jwks_uri
export S3_ENDPOINT=your_s3_endpoint
export S3_ACCESS_KEY=your_s3_access_key_id
export S3_SECRET_KEY=your_s3_secret_access_key
export S3_BUCKET=your_s3_bucket
```
